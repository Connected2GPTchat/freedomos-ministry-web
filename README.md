# FreedomOS Ministry Management System

Hosted **web** test app (browser only — not iOS/Android).

- Figma source: https://www.figma.com/design/nxkQqOD1jCcBtwZr2jCKaC/FreedomOS-Ministry-Management-System--Copy-
- Live URL (after first Actions deploy): https://connected2gptchat.github.io/freedomos-ministry-web/

## Run locally

```bash
npm install
npm run dev
```

## Hosting

GitHub Pages is deployed by `.github/workflows/pages.yml`.
One-time setup: repo **Settings → Pages → Source = GitHub Actions**.

This prototype is mock-data only. No backend, no persisted PII.
